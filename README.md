# «Интернет без риска»

Готовый многостраничный сайт для индивидуального проекта в 9 классе о цифровой безопасности подростков.

## Что есть в проекте

- Три отдельные страницы: главная, угрозы и тест; важные советы и действия при проблеме собраны на главной.
- Современный адаптивный интерфейс в бело-голубо-синей гамме.
- 10 сложных ситуационных вопросов: фишинг, MFA, социальная инженерия, шантаж, взлом аккаунта, QR-коды, Wi‑Fi, поддельный голос и сочетание угроз.
- Один вопрос на экране, случайный порядок при каждом новом запуске, объяснение после ответа, итог и темы для повторения.
- Честная локальная статистика: число прохождений на **этом устройстве**, средний результат и темы с ошибками. Она хранится в браузере (`localStorage`) и не выдаётся за статистику всех посетителей.

## Быстрый запуск

1. Откройте файл `index.html` двойным щелчком в любом современном браузере.
2. Сайт работает без интернета после открытия файлов в браузере.
3. На телефоне меню открывается кнопкой «Меню».

## Бесплатная публикация в интернете: GitHub Pages

1. Создайте аккаунт на [GitHub](https://github.com/), если его ещё нет.
2. Создайте новый репозиторий, например `internet-bez-riska`.
3. Загрузите в него **содержимое этой папки**: `index.html`, остальные HTML-файлы и папку `assets`.
4. В репозитории откройте `Settings` → `Pages`.
5. В блоке **Build and deployment** выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`, затем нажмите `Save`.
6. Через несколько минут GitHub покажет адрес опубликованного сайта. Проверьте на нём страницу теста.

Альтернатива без регистрации в GitHub: создайте бесплатный сайт на [Netlify Drop](https://app.netlify.com/drop) и перетащите в окно папку проекта.

## Важно о статистике

Сайт не использует сервер или базу данных. Поэтому его статистика не объединяет данные разных людей: каждый браузер ведёт свою собственную историю. Это сделано намеренно и честно для учебной демонстрации. Чтобы получить настоящую общую статистику, понадобится подключить отдельную базу данных и согласовать хранение данных с учителем и правилами приватности.

# Короткое описание продукта для защиты

«Интернет без риска» — это учебный сайт для подростков о безопасном поведении в интернете. Он не просто перечисляет правила, а показывает алгоритмы действий в стрессовых ситуациях: при шантаже, фишинге или взломе аккаунта. Главная практическая часть — тест из десяти сложных сценариев. После каждого выбора пользователь сразу видит объяснение, а в конце получает темы для повторения.

## Как реализован сайт

- Сайт написан на HTML, CSS и JavaScript, поэтому его можно бесплатно открыть на компьютере или опубликовать как статический сайт.
- Общие стили находятся в `assets/styles.css`, а мобильное меню — в `assets/site.js`.
- Логика теста находится в `assets/quiz.js`: вопросы случайно перемешиваются, ответ проверяется сразу, а итоги сохраняются только в браузере посетителя.
- Локальное хранение выбрано, чтобы не собирать личные данные подростков и не создавать ложную «общую» статистику.

## Пример выступления на защите — 45 секунд

«Мой проект называется “Безопасность в интернете для МАОУ ЦО №47”. Его цель — научить подростков спокойно и безопасно действовать в интернете, особенно когда на них давят или торопят. На сайте три страницы: на главной собраны правила и действия при шантаже или взломе, отдельная страница объясняет угрозы, а третья содержит практический тест. Варианты ответа в тесте короткие и случайно перемешиваются, поэтому нельзя угадать правильный вариант по месту или длине. После каждого ответа даётся объяснение. Статистика честно обозначена как локальная: она хранится только в браузере устройства. Главная идея проекта — остановиться, проверить источник и обратиться за помощью».
